# HoopVision

HoopVision is my personal basketball analytics project.

My goal is to get really good at system design by building a real app from scratch, starting simple and only adding complexity when the project actually needs it.

The first version will use synthetic basketball game data to calculate basic player and lineup impact metrics, then show the results in a small local dashboard.

## Why I'm Building This

I want to get better at system design by practicing on something that I am genuinely interested in. 

Instead of jumping straight to a big distributed system, I want this project to grow step by step:

- first, clear data models
- then, simple analytics logic
- then, an API
- then, a web dashboard
- later, maybe persistence, jobs, video, and more advanced analytics

## First Version

The first version should be able to:

- load a fake basketball game from a JSON file
- track which players are on the court
- calculate basic plus/minus and efficiency numbers
- explain the results clearly

## Project Principle

Start simple. Add complexity only when there is a real reason. Build. Break. Re-build. And...HAVE FUN!
